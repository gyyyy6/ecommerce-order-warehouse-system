## 第 3 页：系统架构与部署

```text
Windows Host Browser
        │ HTTP :5000
        ▼
Linux VM: Flask 0.0.0.0:5000
        │ psycopg2
        ▼
PostgreSQL 127.0.0.1:5432
```

- UFW 只开放 5000
- 数据库不对外
- `app_rw` 仅 DML，`db_owner` 非超级用户做 DDL

- 订单—明细 1-N
- 订单—物流 1-1（`shipment.order_id UNIQUE`）
- 商品—分类 N-M（`product_category`）

## 第 5 页：关系模式与 3NF

- 主键/外键/唯一/检查约束
- `order_item` 主键 `(order_id, product_id)`
- 不存订单总额、行金额、客户姓名、分类名
- `order_item.unit_price` 是历史快照
- `product.stock` 是当前状态，不是派生列

> 放 3NF 检查表。

## 第 6 页：事务与库存一致性

- 创建订单事务：
  - 插订单 → 插明细 → 条件扣库存 → 插物流 → COMMIT
- 库存不足：`rowcount != 1` → ROLLBACK
- 取消订单：锁订单 → 回补库存 → 改状态 → COMMIT
- 重复取消不重复回补
